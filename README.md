## Repository created for programming and development in the MATLAB language.
![Matlab](https://img.shields.io/badge/Matlab-black?style=for-the-badge&logo=Matlab&logoColor=25fafe) 
![Ocatve](https://img.shields.io/badge/Octave-black?style=for-the-badge&logo=Octave&logoColor=25fafe) 

This repository was built to enhance my studies in the application of MATLAB and Octave in data analysis and scientific computing. 
That said, the goal is to improve on powerful tools offered by MATLAB and Octave for manipulation, visualization and advanced analysis of data, in addition to its use in mathematical modeling, simulations and solving complex problems in the most diverse scientific and engineering areas.

Este repositório foi construído para aprimorar meus estudos na aplicação do MATLAB e Octave em análise de dados e computação científica. 
Dito isto o objetivo é se aprimorar em ferramentas poderosas oferecidas pelo MATLAB e Octave para manipulação, visualização e análise avançada de dados, além de seu uso em modelagem matemática, simulações e resolução de problemas complexos das mais diversas áreas científicas e de engenharia.
